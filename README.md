# chrome-extension-copy-hyperlink

実行したページのタイトルとURLを取得し、ハイパーリンク形式でクリップボードにコピーするChrome拡張機能です。

## 拡張機能追加方法

1. ビルドする。
  ```
  yarn
  yarn build
  ```
2. 拡張機能を追加する。
    1. Chromeの拡張機能管理画面（`chrome://extensions/`）を開く。
    2. 「デベロッパー モード」を有効化する。
    3. 「パッケージ化されていない拡張機能を読み込む」を押下してビルドした`dist`ディレクトリを選択する。
3. 追加された拡張機能（`kurukuruz demo extension`）をピン留めする。（任意）

### 更新時

1. ビルドする。
2. 拡張機能を更新する。
    1. Chromeの拡張機能管理画面（`chrome://extensions/`）を開く。
    2. `kurukuruz demo extension`の右下の更新ボタンを押す。

## 利用方法

ハイパーリンクを取得したいページで`kurukuruz demo extension`のアイコンを押下する。

### 注意事項

- html形式の貼り付けが有効なエディターにはそのまま貼り付けることでハイパーリンク形式になります。  
- Markdown形式のエディター（Zenn, DocBaseなど）への貼り付けを考慮して、テキストで貼り付けた場合はMarkdown形式（`[タイトル](URL)`）が反映されるようになっています。
- GitHubのテキストエリアに素直に貼り付けた場合は「テキスト＋URL」形式（`[[タイトル](URL)](URL)`）になるので、右クリック→「ペーストしてスタイルを合わせる」（または「プレーンテキストとして貼り付ける」）による貼り付けを推奨しています。

## タイトルのカスタマイズ（開発者向け）

クリップボードにコピーする際のタイトル部分をサイトによってカスタマイズすることができます。

### プラグインの作成

[GetTitlePlugin](src/get-title/type.ts)のinterfaceを満たすオブジェクトを作成する。

- `match`: そのプラグインを有効化するURLの指定（`true`を返却するURLでプラグインが有効になる）
- `getTitle`: タイトル文字列の生成（返却した文字列がタイトルになる）
  - タイトルに使用する文字列はメソッド内で`document`や`window`を介して取得してください。

### プラグインの登録

[get-title/index.ts](src/get-title/index.ts)内の`plugins`という配列に作成したオブジェクトを追加する。
